# Earlier feature demonstrations

These are preserved language/handler experiments from before the two runnable
use-case examples. Some exercise generic in-memory mock behavior rather than a
real API contract; some combine assertions and mapping demonstrations. They are
not the recommended templates for API coverage or request-driven service logic.

Start instead with:

- [Testing one backend as an app client](../testing/order-api/README.md)
- [Implementing that backend's operations](../integration/order-service/README.md)

The earlier files retain their relative domain/config paths within this folder.
The old OAuth2 script is illustrative and requires appropriate resource config,
mappings and credentials before it can be run against a real provider.
