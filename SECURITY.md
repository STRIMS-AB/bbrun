# Security

## Reporting a vulnerability

Please report a vulnerability in bbrun by email to **dev@strims.com**, not in a public
issue.

Say what the vulnerability is and what it allows, give the steps or a small example that
shows it, and name the versions or modules concerned.

We confirm that we received it, work on a fix with you, and agree with you on when the fix
and the report are made public.

## Supported versions

Fixes go into the latest release.
